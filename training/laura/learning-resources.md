# Resurse de învățare – Laura

Lista curată, ordonată pe priorități. Toate cele marcate **[free]** sunt gratuite.

## 1. Web fundamentals (luna 1)

### HTML & CSS basics
- **[free]** [MDN Web Docs – HTML Basics](https://developer.mozilla.org/en-US/docs/Learn/HTML) – referința standard.
- **[free]** [CSS Diner](https://flukeout.github.io/) – joc pentru selectori CSS (1h).
- **[free]** [Flexbox Froggy](https://flexboxfroggy.com/) – joc pentru flexbox.

### Browser DevTools
- **[free]** [Chrome DevTools – Intro](https://developer.chrome.com/docs/devtools/overview/) – tab-ul Elements, Network, Console.
- **[free]** YouTube: "Chrome DevTools for beginners" (orice video recent < 30 min).

## 2. JavaScript & TypeScript (luna 2)

### JavaScript
- **[free]** [JavaScript.info](https://javascript.info/) – primele 4 capitole (variables, functions, objects, arrays).
- **[free]** [freeCodeCamp – JavaScript Algorithms](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures/) – partea "Basic JavaScript".

### TypeScript
- **[free]** [TypeScript Handbook – The Basics](https://www.typescriptlang.org/docs/handbook/2/basic-types.html) – doar primele pagini.
- Concepte care contează pentru Playwright: types pentru parametri, interfaces, async/await.

## 3. Playwright (luna 1–3)

### Oficial – cea mai bună sursă
- **[free]** [Playwright Getting Started](https://playwright.dev/docs/intro)
- **[free]** [Codegen tutorial](https://playwright.dev/docs/codegen)
- **[free]** [Best practices](https://playwright.dev/docs/best-practices) – obligatoriu de citit înainte de luna 3.
- **[free]** [Debugging tools](https://playwright.dev/docs/debug) – Trace Viewer e magic.

### Video
- **[free]** YouTube: canalul oficial **"Playwright"** are tutorials de 5–10 min, foarte clare.

## 4. Testing concepts (luna 2–4)

### Cărți
- **"Agile Testing"** – Lisa Crispin & Janet Gregory. Foundation pentru un QA modern. *Recomand audiobook + lectură pe partea de matrice (Quadrants).*
- **"More Agile Testing"** – aceleași autoare, continuare.
- **"xUnit Test Patterns"** – Gerard Meszaros. Citit selectiv: capitole despre Test Doubles, Fragile Test, Setup patterns.

### Articole
- **[free]** [Martin Fowler – Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html)
- **[free]** [Kent C. Dodds – Testing Trophy](https://kentcdodds.com/blog/the-testing-trophy-and-testing-classifications) – perspectivă alternativă.
- **[free]** [Google Testing Blog](https://testing.googleblog.com/) – arhivă imensă.

## 5. Accessibility (luna 5)

- **[free]** [Deque University – Free WCAG courses](https://dequeuniversity.com/curriculum/courses/) – câteva cursuri gratuite.
- **[free]** [axe DevTools browser extension](https://www.deque.com/axe/devtools/) + tutorial.
- **[free]** [WebAIM – Articles](https://webaim.org/articles/) – referință solidă pe WCAG.
- **[free]** [a11y project checklist](https://www.a11yproject.com/checklist/)

## 6. Performance (luna 5)

- **[free]** [web.dev – Lighthouse documentation](https://web.dev/learn/performance/)
- **[free]** [Core Web Vitals explained](https://web.dev/articles/vitals)

## 7. Drupal-specific (transversal)

- **[free]** [Drupal.org – User Guide](https://www.drupal.org/docs/user_guide/en/index.html) – pentru a înțelege ce testezi.
- **[free]** [Drupal JSON:API docs](https://www.drupal.org/docs/core-modules-and-themes/core-modules/jsonapi-module) – important pentru testare API.

## 8. Comunitate

- **[free]** [Ministry of Testing](https://www.ministryoftesting.com/) – community + multe cursuri gratuite.
- **[free]** [Test Automation University](https://testautomationu.applitools.com/) – cursuri video gratuite, multe pe Playwright.
- **[free]** Slack: Playwright Community.

## Plan de citit/parcurs sugerat

| Săpt | Materiale (≈ 5h/săpt) |
|---|---|
| 1–2 | MDN HTML + CSS Diner + Chrome DevTools intro |
| 3–4 | Playwright Getting Started + Codegen |
| 5–8 | JavaScript.info (primele 4 capitole) + Playwright Best Practices |
| 9–12 | TypeScript Handbook (basics) + "Agile Testing" capitolele 1–6 |
| 13–16 | xUnit Test Patterns (selectiv) + practice |
| 17–20 | axe / accessibility cursuri |
| 21–24 | web.dev Performance |

## Reguli de aur

1. **Învață făcând**. Citește 30 min, practică 90 min.
2. **Nu sări la avansat înainte de basics**. Tentația cu Playwright e mare; rezistă fără JS basics.
3. **Întreabă fără frică**. Tech lead-ul și devs sunt aliați.
4. **Documentează ce înveți**. Un Markdown personal cu "what I learned this week" – consolidează.
